# Security Policy

This is the source for a personal static site (Astro), deployed via GitHub Pages. There are no supported version branches — only `main` is maintained.

## Reporting a Vulnerability

If you find a security issue — an exposed secret, a vulnerable dependency, or a misconfigured deploy workflow — please report it privately using [GitHub's private vulnerability reporting](../../security/advisories/new) instead of opening a public issue.

## Scope

- This repository's site source and its GitHub Actions deploy workflow
- Accidentally committed secrets or credentials

Out of scope: vulnerabilities in Astro, npm dependencies themselves, or GitHub Pages — please report those to their respective maintainers (npm dependency CVEs are already tracked automatically via Dependabot).
